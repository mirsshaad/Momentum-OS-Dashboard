# Momentum OS — Premium Personal Operating System

> An Apple, Notion & Linear inspired personal operating system featuring **Daily Operating Dashboard**, **Physical Glow-Up Transformation**, and **Gym OS**.

---

## ✨ Features Overview

### 🏠 1. Daily Operating Dashboard
- **Hero Command Station**: Time-of-day greeting, Level 14 Rank XP bar, Current Mission banner, Active Streak counter, and Life Score gauge (0–100).
- **Core Daily Vitals (6 Radial Progress Rings)**: Workout, Protein, Water, Sleep, AWS Study, Productivity with quick `+`/`-` increment controls.
- **Protocol Checklist**: Task item filters (*All*, *Pending*, *Completed*), sound chimes, confetti completion celebrations, and custom task additions.
- **Quick Stats Cards**: Weight, Calories, Protein, Water, Sleep, and Mood metrics.
- **Schedule Timeline**: 06:00 AM to 01:00 AM daily schedule focus blocks.
- **Analytics & Trends**: Weekly Life Score & Vitals consistency graphs powered by Chart.js.

### ✨ 2. Physical Glow-Up Transformation
- **Body Composition & Measurements**: Track Weight, Body Fat %, Muscle Mass, Waist, Chest, Shoulders, Arms, and Legs.
- **Interactive Before & After Photo Slider**: Touch & mouse draggable split-image comparison slider.
- **Skin Health & Clarity Matrix**: Skin score (88/100), Acne level, Pigmentation, Texture, and Glow score.
- **Hair & Beard Grooming Trackers**: Hair wash toggle button, Barber haircut history, and 15mm heavy stubble beard timeline.
- **Style Evolution & Wardrobe Wishlist**: Signature outfit capsules and checkable shopping wishlist.

### 🏋️ 3. Gym Operating System (Gym OS)
- **Today's Workout Station**: Active split hero banner, Workout Duration Stopwatch, and 1-Click Rest Timer with audio alarm chime.
- **Routine Split Selector**: Switch routines dynamically between **Push**, **Pull**, **Legs**, **Upper**, and **Lower**.
- **Exercise Set Logger**: Interactive sets table (Set #, Reps, Weight, Set Notes, Set Completion checkbox).
- **Personal Records (PRs) Hall of Fame**: Log and display max lifts for Bench Press, Squat, Deadlift, Weighted Pull-Up, and Overhead Press.
- **Strength Progression Analytics**: 1RM strength gain curves per compound lift.
- **Workout Calendar & Volume**: 7-day completion badges and muscle volume tonnage breakdown (42,500 kg total).

## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/mirsshaad/Momentum-OS-Dashboard.git
   cd Momentum-OS-Dashboard
   ```

2. Serve locally with Python (or any web server):
   ```bash
   python -m http.server 8080
   ```

3. Open your browser at:
   ```
   http://localhost:8080
   ```
